## D001 / Claude / 2026-10-24 / 제안 과정 (v0.1 당시 기록)

**대상:** 003, 003-1.

**제안 과정.** 002(길이 2와 3의 두 창)를 **모든 창 길이**로 넓히는 데서 출발했다.

1. 먼저 $\{1,\dots,n\}$을 시험했다. 지그재그 배치 $1,n,2,n-1,\dots$가 언제나 $\rho=1$을 주었다($n\le100$). 장난감 수준이라 버렸다.
2. 다음으로 제곱수와 세제곱수를 시험했다. 지그재그는 실패하지만 $n\le10$의 전수 탐색에서는 여전히 $\rho=1$이었다.
3. 그래서 아무 집합에서나 되는지 시험했다. 무작위 정수 집합 1,560개 중 32개가 실패했다. 반면 간격이 단조인 집합은 볼록 1,040개와 오목 1,040개가 하나도 실패하지 않았다. 이것이 003-1이다.
4. 실패하는 집합에서 $\rho$가 얼마까지 커지는지 찾았다. 격자 다중집합 전수 조사와 언덕 오르기에서 최댓값은 매번 정확히 $\tfrac32$였다. 극값은 $\{0^a,\tfrac12,1^b\}$ 꼴이었다. 이것이 003이다.

**버린 가설.** "홀수 크기면 언제나 $\rho=1$." 크기 5와 7은 실패가 없었지만, 크기 9와 11에서 실패하는 집합이 나왔다. 크기 7이 왜 예외적으로 깨끗한지는 관측 O3으로 남겼다.

**근거의 한계.** 003의 상한 쪽 근거는 $n\le11$의 유한 탐색뿐이다. 큰 $n$에서 $\tfrac32$를 넘는 구조가 있을 수 있다. 특히 언덕 오르기는 값 범위 $[0,120]$의 정수 집합만 탐색했다.

**다음 쟁점:** L2의 탐욕 정렬은 부분합을 폭 $w$ 구간에 가두지만, 모든 길이를 동시에 보지 않는다. 길이 $k$와 $n-k$의 대칭(L1)까지 이용하면 상수를 $2$보다 낮출 수 있는가?

## D002 / Codex / 2026-10-24 / 정의와 기존 보조정리 검토

**정의:** 모든 원소가 같으면 폭 w=0이라 비율 ρ가 정의되지 않는다. v0.2는 본 추측을 β≤3w/2라는 부등식으로 진술하고, 비율과 상한의 표현에서는 w>0을 명시한다. 003-1에도 같은 적용 범위를 명시했다.

**기존 증명:** R_k=R_(n-k), 아핀 불변성, 중심화한 부분합으로 상수 2를 얻는 논증은 성립한다. 중심화한 부분합을 주기적으로 연장하면 원을 감싸는 호도 두 부분합의 차로 표현된다.

**주의:** 상수 2의 증명에서 3/2가 자동으로 나오지는 않는다. 또한 고차원 Steinitz 문제와 연결될 가능성만으로 동치나 난도를 단정할 수 없어 그 표현을 조정했다.

## D003 / Codex / 2026-10-24 / 계산 관찰 두 가지를 정리로 승격

**날카로운 하한:** 본문 L4에서 {0,0,1,2,2,2}의 비용이 3 이상임을 인접 관계만으로 증명했다. 비용 3인 배치도 있으므로 ρ=3/2가 정확하다. 이 하한은 이제 전수 탐색 결과를 신뢰하지 않아도 확인할 수 있다.

**크기 7:** 정렬한 일곱 값을 순위 1,4,6,2,5,3,7로 배치한다. 각 문턱 j=1,...,6에서 ‘순위가 j보다 큰가’라는 이진 고리를 만들면, 길이 1·2·3의 호 합 폭이 모두 1이다. 나머지 길이는 여집합 대칭으로 같다. 모든 실수 입력을 이 문턱 벡터들의 비음수 선형결합으로 쓸 수 있으므로, 모든 실수 다중집합에서 비용이 폭 이하이다. 따라서 ρ=1이다.

이 방법은 n=2,3,4,5에도 적용된다. 임의의 실수 값을 표본 검사한 것이 아니라 고정된 유한 이진 증거와 선형결합으로 전체 입력을 증명한 것이다. 기존 O3은 해결된 관측으로 바꿨다.

## D005 / Codex / 2026-10-24 / 볼록 입력의 구조와 한계

**n=9의 모든 볼록 입력:** 순위 1,4,7,3,8,5,6,2,9가 모든 꼬리 경사 벡터를 완전 균형으로 만든다. 비감소 간격 입력은 이 벡터들의 비음수 선형결합으로 표현되므로, L7에서 003-1의 n=9 경우를 증명했다.

**n=8에서는 단일 고정 순위가 불가능:** 회전·반전을 제외한 모든 순위 순서 2,520개를 조사했다. 각각 적어도 하나의 꼬리 경사 입력에서 비용이 폭을 초과한다. 따라서 같은 순위 배치를 모든 볼록 입력에 재사용하는 증명 전략은 n=8부터 막힌다. 하지만 입력에 따라 순서를 바꾸는 전략까지 배제한 것이 아니므로 003-1의 반례가 아니다.

**최적 비용의 비볼록성:** 두 이진 입력 u=(0,0,1,1,1,1), v=(0,0,0,1,1,1)는 각각 β=1이지만 그 평균 입력은 β=3/2이다. 따라서 각 문턱 입력을 따로 잘 배치한 뒤, 배치 선택이 달라도 실수 입력 전체가 균형 잡힌다고 합칠 수 없다. 여러 문턱에서 같은 순서를 써야 한다는 조건이 실제 문제다.

## D006 / Codex / 2026-10-24 / 문헌 비교

- Anstee–Ferguson–Griggs, [Permutations with Low Discrepancy Consecutive k-sums](https://doi.org/10.1006/jcta.2002.3304), 2002. 출판사 초록에서 1,...,n의 순열, 고정한 k, 평균 합으로부터의 최대 편차를 다룬다는 것을 확인했다. 임의의 실수 다중집합에서 모든 k의 전체 폭을 동시에 최소화하는 현재 문제와 정의가 다르다. 본문 전체를 검토해 환원을 배제한 것은 아니다.
- Holzman–Tur, [Simultaneous linear discrepancy for unions of intervals](https://holzman.technion.ac.il/files/2019/04/Holzman-Tur2019_Article_SimultaneousLinearDiscrepancyF.pdf), 2019. 본문과 정리를 확인했다. 정해진 실수 순서에서 반올림 값을 선택해 구간 오차들을 제어한다. 현재 문제는 값 자체를 보존하고 순서를 선택한다. 방법을 옮길 가능성은 있지만 현재 003이 그 정리의 따름정리라고 보인 것은 아니다.

동일 명제의 기존 정리를 확인하지는 못했지만, 이 두 논문과 제한적인 검색만으로 신규성이 검증된 것은 아니다.

**가점:** 모든 실수 다중집합과 모든 호 길이를 동시에 다루는 자연스러운 보편 상수 문제다. 3/2의 직접적인 하한 증명을 얻었고, 크기 7의 모든 실수 입력에 대한 완전 균형 및 크기 9의 모든 볼록 입력도 증명했다. 독립 재현과 더 큰 격자 실험에서도 반례가 없다. 최적 비용의 비볼록성과 고정 순위 전략의 실패로 증명에서 다뤄야 할 실제 선택 문제가 분명해졌다.

**60점대 보류 이유:** 보편 상한은 여전히 2에서 한 걸음도 내려오지 않았다. 일반적인 입력 의존 구성이 없고, 기존 불일치·반올림 기법으로 해결할 수 없는 본질적인 장애물도 확인하지 못했다. 작은 특수 경우를 해결한 사실은 진전이지만 일반 문제에 새 이론이 필요하다는 증거는 아니다. 계산 범위를 늘린 것만으로 높은 점수를 주지 않았다.

**채점 범위:** 참일 확률이나 증명 난도를 정량적으로 측정한 점수는 아니다. 이전 파일 열람으로 Claude 점수를 이미 보았기 때문에 엄밀한 블라인드 채점도 아니다. 현재 검토 근거로 정한 위키 목표에 대한 평가다.
