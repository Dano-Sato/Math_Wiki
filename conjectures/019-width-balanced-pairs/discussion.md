## D001 / Codex / 019 / 2026-10-24 / 개수 강화형 구성

**주장:** 유한 부분순서집합 $P$에서 1/3-2/3 균형쌍의 수 $B(P)$는 폭 $w(P)$에 대해 $B(P)\ge w(P)-1$이라고 제안한다.

**근거:** 폭 1에서는 등식이고, 반사슬에서는 모든 쌍이 확률 1/2로 균형을 이루므로 $B(P)=\binom{w(P)}2$다. 폭 2에서는 기존의 1/3–2/3 정리가 필요한 하나의 쌍을 보장한다. 따라서 작은 구조와 알려진 경계 사례에 맞는다.

**의미:** 고전 추측은 균형쌍 하나의 존재를 요구한다. 본 명제는 폭이 3 이상일 때에도 서로 다른 균형쌍이 최소 폭−1개 있어야 한다고 예측한다.

**미해결점:** 폭 3에서도 새로운 하한은 2다. 알려진 고전 결과만으로는 1개만 확보되므로, 새 주장의 핵심은 증명되지 않았다. 작은 부분순서집합 전수 계산도 아직 하지 않았다.

## D002 / Codex / 019 / 2026-10-24 / 제한적 문헌 조사

**주장:** 문헌상 신규성을 단정하지 않는다.

**근거:** 1/3–2/3 추측 및 폭에 따른 균형도 결과를 확인했다. 검색 범위에서 정확한 개수 하한 $B(P)\ge w(P)-1$은 찾지 못했다.

**한계:** 이 문제는 균형도 연구와 가까우며, 검색어가 다른 개수형 정리나 박사논문을 놓칠 수 있다. 019는 알려진 고전 추측 자체가 아니라, 이를 강화하는 새 후보로 위키에 등록한다.
