## D001 / Claude / 2026-10-24 / 제안 과정

**대상:** 007, 007-1.

**출발점.** 001~005는 수열과 원 위 배치였다. 이번에는 순열 정렬과 Cayley 그래프를 택했다. 모든 길이의 뒤집기로 정렬할 때 지름은 $n-1$이다. 뒤집는 길이를 소수로 제한하면 어떻게 되는지 계산했다.

**관찰.**

1. 지름은 $n=2,\dots,10$에서 $1,2,4,4,6,7,8,9,10$이었다. $n\ge6$에서 정확히 $n$이다. 이것이 007이다.
2. 가장 먼 순열을 보니 $n=6,8$에서 완전 역순이 들어 있었다. 역순까지의 거리만 따로 계산했다. 소수 $n$이면 1, 짝수 $n$이면 정확히 $n$, $n=9$이면 4였다. 이것이 007-1이다.

**문헌 확인.** 웹 검색에서 Chen–Skiena의 고정 길이 뒤집기("Sorting with Fixed-Length Reversals", Discrete Appl. Math. 1996)와 길이 가중 뒤집기(Pinter–Skiena, Bender 외)를 확인했다. 소수 길이로 제한한 판은 찾지 못했다. OEIS에서 지름 수열 $1,2,4,4,6,7,8,9,10$도 일치하는 항목이 없었다. 다만 이는 신규성의 증거가 아니다.

**근거의 한계.** 전수 계산은 $n!$에 막혀 $n=11$까지가 한계다. 007은 $6\le n\le11$의 여섯 값에 기대고 있다. 작은 $n$의 패턴이 큰 $n$에서 깨진 예는 많다(002의 초기 후보 $E_n=\lceil n/2\rceil$도 그랬다). **이 위키의 추측 중 증거가 가장 얇은 편이다.**

**다음 쟁점:** 하한 쪽이 더 어렵다. $n$번 미만으로 $w_0$를 정렬할 수 없음을 보이려면 끊긴 이웃 수보다 강한 불변량이 필요하다.

## 재현 방법

이 폴더에서 Go 1.21 이상과 Python 3.10 이상으로 실행한다.

```powershell
go run bfs.go -max 11 -lengths prime -output experiment.json
go run bfs.go -max 9 -lengths all -output check_all_lengths.json
python reverse_distance.py --max 12
```

둘째 줄은 구현 검증용이다. 모든 길이의 지름 $n-1$을 재현해야 한다. $n=11$의 BFS는 약 4천만 상태로 몇 분, 역순 거리 $n=12$는 1분 정도 걸린다.
