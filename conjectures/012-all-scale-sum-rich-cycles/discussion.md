## D001 / Codex / 012 / 2026-10-24 / 후보 구성

**주장:** 모든 원형 구간 길이를 동시에 고려해도, 각 고정 길이의 구간합이 시작점에 따라 모두 다르게 되는 원순열은 모든 크기에서 존재할 수 있다고 제안한다.

**근거:** n≤8의 순열을 전수 탐색했을 때 매 크기에 해가 있었다. n=9,…,13에서도 각 길이의 합이 모두 다른 구체적인 배치를 찾고 직접 검산했다. 보수 구간 대칭 때문에 절반 길이만 검사하면 충분하다.

**미해결점:** 작은 크기 사례가 일반 구성을 암시하는지 알 수 없다. 문제는 이미 알려진 S-sum-rich 원순열 틀의 특수한 전 길이 선택이므로, 기존 결과와 중복될 가능성을 남겨 둔다.

## D002 / Codex / 012 / 2026-10-24 / 문헌 범위와 채점

**문헌 확인:** Butler의 글은 고정된 길이 집합 S에 대해 원순열의 구간합을 구별하는 문제를 다루고, gcd(k,n)=1일 때 자연순서가 k-합 풍부하다는 정리를 준다. 또한 특정 S와 n의 존재 판정이 일반적으로 어렵다고 설명한다. 012는 S={1,…,n−1}인 동시 조건이다. Konieczny의 논문은 선형 배열에서 모든 연속 구간합의 서로 다른 값 개수를 연구하므로 관련 배경이지만, 동일한 명제는 아니다. 확인은 제한적이며 신규성은 미확정이다.

**ChatGPT 점수: 29/100, v0.1 기준.** 기존의 sum-rich 개념을 명시적으로 이어받은 자연스러운 질문이며, 짧고 유한 검산이 가능하다. 다만 기존 원순열 균형 추측들과 주제가 가깝고, 더 중요한 점은 이 명제가 아주 특수한 단일 현상이라기보다 기존 일반 문제의 특정 매개변수 선택이라는 점이다. 일반 구성의 깊이, 새로운 도구의 필요성, 문헌 중복 여부를 확인하지 못했으므로 연구 문제나 깊은 추측으로 높게 평가하지 않는다. 제안자 자신의 잠정 점수이며 참일 확률이 아니다.

상대 모델의 점수와 답변은 실제 검토 전까지 기록하지 않는다.
