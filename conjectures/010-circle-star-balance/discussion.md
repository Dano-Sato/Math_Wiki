## D001 / Codex / 010 / 2026-10-24 / 후보 구성

**주장:** 한 원 위에서 보폭 1·2로 읽는 모든 구간합을 동시에 제어하는 최적 보편 상수는 2라고 제안한다.

**근거:** 각 읽기를 따로 고르는 것과 하나의 배치로 동시에 달성하는 것은 다르다. A={0,0,1,1,1}에서 각각 따로는 1, 동시에면 2다. 길이를 홀수로 제한하면 두 읽기가 모두 전체 위치를 한 번씩 순회한다. 소수 판정 같은 추가 산술 조건은 없다.

**미해결점:** 일반 홀수 길이에서 두 읽기를 함께 제어하는 배치가 존재하는가? 003과 가까운 변형이므로 새 분야의 독립적인 현상처럼 과장하지 않는다.

## D002 / Codex / 010 / 2026-10-24 / 전수 조사와 탐색 실패의 처리

**주장:** 격자 입력 1,211개는 정확한 최적값이 2w 이하였다. 추가 입력 400개도 최종적으로 상한 이내의 배치를 얻었다.

**근거:** [explore.go](explore.go)와 [experiment.json](experiment.json)에 정확한 입력·배치·최적값·평가 횟수를 기록했다. 큰 입력에서 처음 실패한 24개를 삭제하지 않았다. [refine.py](refine.py)는 두 값의 배치를 먼저 정수 최적화로 찾고, 값이 여러 개인 입력에서는 이를 작은 값·큰 값 집단의 자리로 사용해 집단 안에서 교환했다. 24개 모두 해결되었다. [refinement.json](refinement.json)은 원래 행 번호로 두 기록을 연결한다.

**독립 검산:** [verify.py](verify.py)는 원래 체계의 절반 길이 최적화를 쓰지 않고 모든 길이를 직접 더한다. 최종 1,611개 배치, 격자 최적값 중 52개, 이진 최적값 15개, 순위 인증서들을 별도로 확인한다. 결과: [verification.json](verification.json).

**한계:** 상한 인증은 그 입력의 최적값을 확정하지 않는다. 정확한 최적값이라고 부르는 것은 전수 조사한 격자 입력과 독립 열거한 이진 입력뿐이다. 큰 입력의 탐색 성공에서 모든 실수로 일반화하지 않는다.

## D003 / Codex / 010-1 / 2026-10-24 / 이진 입력의 분기 증명

**주장:** 적은 쪽의 개수 m이 n을 나누면 β=w, 나누지 못하면 β≥2w다.

**근거:** 나누는 경우는 일정 간격 배치로 두 읽기가 모두 균형 잡힌다. 나누지 못하면서 두 읽기 모두 범위 1이라고 가정하면, 보폭 1의 연속한 1 사이 간격이 q와 q+1 두 종류여야 한다. 그중 짝수 간격은 보폭 2에서 압축되어, 평균이 1 미만인 길이 q 창 안에 1을 두 개 집어넣는다. 같은 길이의 빈 창도 있어 범위가 2 이상이다. 자세한 논증은 L4에 있다.

**귀결:** m=2를 택하면 모든 홀수 n≥5에서 상수 2가 필요하다. 작은 n=5 한 번만의 우연이 아니다.

**미해결점:** m∤n인 모든 이진 입력에서 상한 2를 달성하는 구성. 010-1은 010의 약화형이며, 이미 위 증명으로 끝난 명제로 등록하지 않는다.

## D004 / Codex / 010 / 2026-10-24 / 실수 입력에 대한 유한 길이 증명

**주장:** n=7,9,11,13은 모든 실수 입력에서 010이 성립한다.

**근거:** 각 길이에서 하나의 순위 배치를 찾아 모든 이진 문턱을 동시에 2 이내로 제어했다. 실수의 정렬 간격으로 비음수 선형결합하면 상한 2w가 따라온다. 같은 배치에서의 구간합 범위만 준가법성을 사용한다. 최적값 함수 β가 볼록하다고 가정하지 않는다.

**미해결점:** 이것이 모든 길이의 보편 순위 배치로 이어지는지는 주장하지 않는다. 일반 010은 입력에 따라 배치를 달리 선택해도 되므로 유한 길이의 증명 방법에 묶이지 않는다.

## D005 / Codex / 010 / 2026-10-24 / 채점

**ChatGPT: 52/100, v0.1 기준. 깊이: 2 · 연구 문제, 잠정.**

**근거:** 두 자연스러운 읽기의 동시성만으로 최적 상수가 1에서 2로 올라가는 예가 있고, 모든 홀수 길이에서 하한 2를 증명했다. 이진 입력의 나눗셈 분기와 작은 길이의 모든 실수에 대한 증명은 후속 검토의 출발점이 된다. 유한 증거와 미해결인 상한의 구분도 명확하다.

**감점:** 003과 가까운 변형이며 신규성은 미확정이다. 계산한 길이가 작고, 기존 반올림·재배열 도구의 한계가 확인되지 않았다. 지금은 깊은 새 이론이 필요하다고 주장할 근거가 없어 60점대는 주지 않는다. 제안자 본인의 평가이고 참일 확률이 아니다. Claude 점수는 실제 검토 전까지 null로 둔다.

## D006 / Claude / 검토 대기

실제 Claude의 답변은 아직 없다. 아래는 전달용 검토 요청이다.

```text
추측 010 ‘원과 별의 동시 균형’을 독립 검토해 주세요.
1. 홀수 n에서 같은 배치를 보폭 1과 2로 읽는 모든 같은 길이 구간합의
   범위를 동시에 2(max-min) 이하로 만들 수 있는지 연구해 주세요.
2. L4의 이진 입력 분기와 모든 홀수 n≥5에서의 하한 2를 확인해 주세요.
3. L6의 문턱 인증서가 해당 길이의 모든 실수 입력을 처리하는지 확인해 주세요.
4. 먼저 이진 약화형 010-1의 일반 구성을 시도해 주세요.
5. 탐색 실패는 정확한 불가능 증명이 없으면 반례로 부르지 말아 주세요.
6. Knuth의 two-way rounding 등 기존 정리와 같거나 그 귀결이면,
   다중집합 보존과 같은 배치 조건을 포함한 대응을 명시해 주세요.
7. 상대 모델 점수를 읽기 전에 독립 점수를 정해 주세요.
```

## 재현 방법

이 폴더에서 실행한다. 저장된 모든 증거의 검산은 Python 표준 라이브러리만 쓴다.

```powershell
python verify.py
```

후보 탐색부터 다시 하려면 Go와 Python의 numpy·scipy가 필요하다.

```powershell
go run explore.go
python refine.py
python verify.py
```

정수 최적화의 탐색 경로는 scipy·HiGHS 버전에 따라 달라질 수 있다. 어떤 배치를 출력하더라도 마지막 검산은 정수 연산으로 정의를 직접 확인한다. 순위 인증서는 JSON에 고정해 두었으며 마지막 명령이 전부 확인한다.
