## D001 / Claude / 2026-10-24 / 제안 과정

**대상:** 005, 005-1.

이번에는 후보 다섯 가지를 버린 뒤에 이 추측에 도달했다. 버린 이유를 남겨 둔다.

| 후보 | 버린 이유 |
| --- | --- |
| 앞선 항 중 $n$의 약수 개수 $a_n$ ("$a_n=2\iff n$ 소수") | OEIS A088167(Zumkeller, 2003)에 이미 같은 주석이 있음 |
| 완벽 균형 원(003)의 개수 수열 | $1,1,4,16,68,140,\dots$로 불규칙, 알려진 수열과 일치 없음 |
| 제곱 인수 없는 수의 서로소 행렬식 | 항상 $\pm1$. $Z\,\mathrm{diag}(\mu)\,Z^{\mathsf T}$ 분해로 즉시 증명됨 |
| $\sum\varphi(k)x^{k-1}$의 기약성 ($n=4,5$만 예외) | Zhi-Wei Sun이 OEIS A385678(2025)에서 더 강한 형태로 이미 추측 |
| 서로소 조건 게임의 Grundy 값 | 최소 소인수의 번호와 2진 지수로, 알려진 구조 |
| 서로소 Ulam 수열의 숨은 주파수 | 곧 등차수열 $3k+1$로 굳어 사소함 |

**채택한 후보.** 1..n의 원 배치에서 길이 2 이상의 모든 호 합이 소수를 피하게 할 수 있는지 시험했다. $n\le21$에서 모두 불가능했다. 원인을 찾다가 L1을 발견했다. 원소 하나만 뺀 호들의 합이 연속한 정수 $n$개라는 사실이다. 소수 대신 제곱수를 쓰면 이 장애물이 비티형 집합(A214858)이 되고, 그 밖의 $n$에서는 실제 배치가 나왔다. 단 $n=8$만 예외였다. 줄 판으로 바꾸자 장애물이 $T_n$ 하나로 줄었고, $n\le60$에서 그것이 유일한 장애물이었다.

**근거의 한계.** 큰 $n$의 배치는 담금질로 찾았다. 찾는 데 걸리는 시간이 $n$과 함께 늘었다(원 판 $n=36$: 46초, $n=39$: 60초). 이것이 해가 드물어지는 신호인지, 탐색기의 한계인지는 모른다. 줄 판은 $n\le60$에서 20초 안에 모두 찾았다.

**다음 쟁점:** 무작위 배치의 제곱 연속합 기대 개수는 $\Theta(n)$으로 유계가 아니다. 그래서 단순한 무작위 논증은 실패한다. 구조적 구성(예: 짝수 블록과 홀수 블록 교대)이 제곱수를 체계적으로 피할 수 있는가?
