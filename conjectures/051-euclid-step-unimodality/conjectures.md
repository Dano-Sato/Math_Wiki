# 분모 상한 아래 유리수의 유클리드 단계 수 분포는 단봉형이다

> 기약 유리수의 분모를 제한했을 때, 표준 유클리드 알고리즘의 정확한 나눗셈 횟수 분포는 모든 단계 범위에서 단봉형일까?

| 항목 | 내용 |
|---|---|
| 버전 | 0.1 |
| 상태 | 미해결 추측 |
| 분야 | 해석적 수론 · 연분수 |
| 깊이 | 2 |

## 정의

정수 `N ≥ 2`와 `k ≥ 1`에 대해

`A_N(k) = #{(a,b) : 1 ≤ a < b ≤ N, gcd(a,b)=1, 표준 유클리드 알고리즘이 (a,b)에서 k회의 나눗셈 후 종료}`

로 둔다. 나눗셈 알고리즘의 시작 입력은 큰 수부터인 순서쌍 `(b,a)`다. 따라서 `k`는 몫 0의 초기 나눗셈을 넣지 않는 표준 유클리드 나눗셈 횟수이며, `a=1`인 모든 쌍은 한 번에 끝난다. `A_N(k)>0`인 연속된 유한 구간에서 단봉형이라는 말은 어떤 `m`이 있어 `A_N(1) ≤ … ≤ A_N(m)`이고 `A_N(m) ≥ …`가 끝까지 성립한다는 뜻이다. 봉우리의 평탄부는 허용한다.

## 추측 0.1

모든 `N ≥ 2`에서 `(A_N(k))_{k≥1}`의 양의 지지집합 위 분포는 단봉형이다.

이 추측은 분모 `b ≤ N`인 모든 기약분수 `a/b ∈ (0,1)`의 집합, 즉 Farey 분수 집합에 대한 유클리드 나눗셈 횟수의 정확한 유한 분포를 말한다. 점근적 정규분포나 평균에 대한 정리만으로 각 유한 `N`에서의 단봉성은 따라오지 않는다.

## 예비 계산

`verify.py`는 각 `b ≤ 3000`의 기약분수에 대한 나눗셈 횟수를 세어 모든 분모 상한 `2 ≤ N ≤ 3000`의 히스토그램을 점진적으로 확인한다. 이 유한 계산은 일반 추측의 증명이 아니다. 로그오목성은 더 강한 후보였으나 `N=405`에서 실패한다. 이때 단계별 계수는 `[404, 2084, 5691, 9930, 11909, 10151, 6175, 2681, 802, 145, 12, 1]`이고 마지막 내부 부등식 `12² ≥ 145·1`이 깨진다.

## 문헌 확인 범위와 한계

Minelli–Sourmelidis–Technau는 분모가 제한된 Farey 분수에서 유클리드 알고리즘 단계 수의 평균과 변형 알고리즘의 점근식을 연구한다. Baladi–Vallée의 정규분포 결과도 관련 배경이다. 이번 제한 검색에서 모든 유한 `N`에 대한 정확한 히스토그램 단봉성 진술은 찾지 못했다. 이는 우선성이나 문헌상 독창성을 보증하지 않으며, 관련 문헌의 전수 조사는 하지 않았다.
