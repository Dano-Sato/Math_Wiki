## D001 / Codex / 021 / 2026-10-24 / 버전 이력 및 중복 제거

**v0.1 (폐기):** $H(T_n)$을 $n!/2^{n-1}$로 나눈 값이 1에 가까워진다는 전체 경로 수 집중. 지시변수 두 번째 모멘트 전개에서 분산이 $O(1/n)$으로 떨어지는 방향이 보여, 이는 깊이 있는 신규 추측으로 남기기에 약했다.

**v0.2 정규극한 후보 (폐기):** $H(T_n)$의 정규화 편차가 정규분포로 수렴한다는 강화안. 문헌 조사에서 Janson, “Hamilton cycles in a random tournament” (1995)이 전체 해밀턴 순환 수의 점근 정규성을 이미 증명한 사실을 확인했다. 경로 수까지의 관계를 여기서 완전히 환원하지 않았더라도, 같은 계열 통계의 정규극한을 새 70점 추측으로 제시하는 것은 문헌 중복 우려가 커 후보에서 제외했다. 이전 버전을 삭제하지 않고 이 판단을 기록한다.

## D002 / Codex / 021 / 2026-10-24 / 간선별 평균과 분산 계산

고정한 방향 간선 $e=u\to v$를 포함하는 각 방향 해밀턴 순환에서 $e$를 지우면 $v$에서 시작해 $u$에서 끝나는 해밀턴 경로가 된다. 따라서 $C_e$는 해당 끝점 경로 수와 같다. 경로 순서 수는 $(n-2)!$이고, 각 순서의 나머지 $n-1$개 방향이 맞을 확률은 $2^{-(n-1)}$이므로 $\mu_n=(n-2)!/2^{n-1}$다.

두 경로 순서의 공통 간선을 고정해 두 번째 모멘트를 전개한다. 내부 연속 인접 run의 홀수 길이 부호합은 상쇄되고, 길이 2 run은 $2(n+O(1))/(n+O(1))_2=2/n+O(n^{-2})$ 규모의 기여를 준다. 시작·끝 경계에서 같은 이웃을 택하는 두 독립 경계 정합이 각각 $1/n+O(n^{-2})$를 더한다. 나머지 양립 가능한 겹침은 $O(n^{-2})$로 제어되는 것으로 전개되어

$$
\operatorname{Var}(C_e/\mu_n)=\frac4n+O(n^{-2}).
$$

[explore.py](explore.py)는 고정 끝점 순열 가중 DP로 이 두 번째 모멘트를 유한 $n$에서 정확히 계산한다. $n=12,18$에서 $n\operatorname{Var}$는 각각 약 5.817, 5.053이며 4로 내려가는 방향이다. 이 유한 표는 점근 증명 대신 전개를 검산하는 자료다.

## D003 / Codex / 021 / 2026-10-24 / 간선별 최댓값 추측 구성

**주장:** 방향 간선마다 정규화된 순환 수가 같은 평균에 접근하며, 전체 $\binom n2$ 간선의 최대 상대오차는 $O_{\mathsf P}(\sqrt{\log n/n})$다.

**유한 계산:** seed 20261024로 $n=4,\ldots,12$의 무작위 토너먼트를 각각 30개 생성했다. 각 토너먼트에서 모든 시작점별 subset DP를 수행해 끝점별 해밀턴 경로 수를 정확히 구했고, 역방향 경로 수로 각 실제 방향 간선을 닫는 순환 수를 얻었다. 간선별 RMS 상대오차의 표본 평균은 $n=4$의 약 1.66에서 $n=12$의 약 0.67로 낮아졌다. 간선별 최댓값 편차는 비단조적이고 여전히 큰 편이다. 현재 표본은 제안한 속도에 대한 강한 증거가 아니다.

## D004 / Codex / 021 / 2026-10-24 / 문헌 대조와 점수

**문헌:** Janson (1995)은 전체 해밀턴 순환 수의 정규극한을 증명했다. Wormald의 “Tournaments with many Hamilton cycles”는 전체 순환 수의 평균·분산 및 극값 문제를 다룬다. `random tournament Hamilton cycles edge counts`, `Hamilton cycles through each arc random tournament`, `edge distribution Hamilton cycles tournament`, `maximum edge cycle count random tournament` 검색에서는 각 간선별 순환 수의 최댓값 편차에 대한 동일한 확률 상계를 찾지 못했다. 제한 검색일 뿐이다.

**ChatGPT 자체 채점: 71/100, v0.2 기준. 깊이: 3 · 확률 조합론의 국소-전역 집중 문제, 잠정.**

**가점:** 총 순환 수의 평균·정규극한과 구별되는 간선별 동시 균등성 문제다. 간선 한 개의 정확한 평균과 $4/n$ 분산 규모 분석이 있고, 전체 간선 수가 $\Theta(n^2)$라 고차 모멘트와 상관 구조가 실제 난점으로 남는다. 선행 결과를 새 추측처럼 재사용하지 않도록 버전을 바꿨다.

**감점:** 간선별 최댓값은 작은 유한 표본에서 아직 감소 속도가 명확하지 않다. 증명된 문헌 중복이 없다는 결론은 검색 범위에 한정되며, 근접한 결과를 더 찾으면 명제 차이와 점수를 다시 검토해야 한다. 이 점수는 제안자의 잠정 품질 평가이며 참일 확률이 아니다.

## D005 / Codex / 021 / 2026-10-24 / 자체 점수 보수적 재평가

사용자가 71점이 적절한지 물어 재검토했다. 71점은 한 간선의 평균·분산 계산이 본 추측의 핵심인 최댓값 집중을 뒷받침하는 정도를 과대평가했다. 현재 계산은 유한 규모의 모멘트 전개와 소표본 탐색이며, 전체 간선에 대한 꼬리 상계는 없다. 문헌 검색 또한 제한되어 신규성 확신을 높게 줄 근거가 부족하다. 추측의 구체성과 가능한 연구 난점은 인정하되, 제안자 자체 점수를 **71에서 66/100으로 하향**한다. 명제와 버전은 바꾸지 않는다.
