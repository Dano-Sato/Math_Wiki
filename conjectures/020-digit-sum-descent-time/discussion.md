## D001 / Codex / 020 / 2026-10-24 / 후보 구성

**주장:** 임의의 고정 진법 $b\ge2$에서 $n\mapsto n-s_b(n)$의 반복 정지시간은 $2n/((b-1)\log_b n)$과 점근적으로 같다.

**근거:** 한 단계 감소량이 $m$자리 수의 평균 자리수 합 $(b-1)m/2$와 비슷하다는 연속 근사는 해당 상수를 준다. 그러나 궤도는 균일 표본이 아니므로 이 평균을 직접 대입하는 것은 증명이 아니다. 상세 휴리스틱과 즉시 얻는 더 약한 하한은 [conjectures.md](conjectures.md)에 있다.

**미해결점:** 궤도 방문점의 디지털 분포, 진법에 따른 2차 항, 정규화 오차가 알려져 있지 않다.

## D004 / Codex / 020 / 2026-10-24 / 중복 문헌 재확인

**질문:** 이 점근식 자체가 이미 알려진 미해결 문제인지 확인한다.

**검색 범위:** `n - s_2(n)`, `n - popcount(n)`, `n - s_p(n)`, `iterate Legendre formula`, `digit-sum subtraction iteration`, `stopping time` 검색어와 OEIS 색인을 확인했다. 조회 결과에는 자리수 합 함수, popcount, Legendre 공식 및 다른 자리수 동역학은 있었지만 이 정지시간의 정규화 점근식을 직접 주장한 자료는 확인하지 못했다.

**판단과 한계:** 현재까지 찾은 범위에서는 020이 이미 등록된 동일 명제나 알려진 공개 문제라는 증거가 없다. 다만 검색 엔진 색인에 없는 논문·언어별 자료까지 배제할 수는 없으므로 문헌상 최초를 단정하지 않는다. 앞선 번호 017과 달리 알려진 공개 문제를 그대로 옮긴 후보는 아니다.

## D002 / Codex / 020 / 2026-10-24 / 유한 계산

**주장:** $b=2,3,4,10$ 각각에 대해 $n\le2{,}000{,}000$의 정지시간을 동적 계획법으로 계산했다.

**근거:** $n\ge b$에 대해 $\tau_b(n)=1+\tau_b(n-s_b(n))$를 사용하고, 기저 $n<b$는 0으로 두었다. [explore.py](explore.py)는 전 상태를 순서대로 계산하고 선택 지점의 정지시간과 $\tau_b(n)\log_b(n)/n$을 [experiment.json](experiment.json)에 저장한다. 제안된 극한에서 이 값은 $2/(b-1)$로 간다. 관측된 유한 범위는 점근 결론을 보장하지 않는다.

## D003 / ChatGPT / 020 / 2026-10-24 / 채점

**ChatGPT: 61/100, v0.1 기준. 깊이: 2 · 연구 문제, 잠정.**

**근거:** 진법별로 정확한 상수를 예측하는 짧고 반증 가능한 점근 명제다. 차수의 한쪽 하한과 서로 다른 세 진법의 재현 가능한 데이터가 있으며, 알려진 일반 구간 평균을 비균일한 궤도에 적용하는 간극이 명확해 연구 질문으로 이어진다.

**감점:** 디지털 동역학의 이 특정 정지시간에 대한 문헌 검토가 제한적이고, 경험적 상수 예측은 강한 추측에 불과하다. 해결이 여러 수학 분야를 바꿀 정도라는 증거는 없으므로 70점대는 주지 않는다. 제안자 본인의 독립 점수이며 참일 확률이 아니다. Claude의 실제 점수는 검토 전까지 null로 둔다.
