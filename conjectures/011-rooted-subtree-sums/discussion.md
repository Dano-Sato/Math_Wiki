## D001 / Codex / 011 / 2026-10-24 / 후보 구성

**주장:** 임의의 뿌리 있는 나무의 꼭짓점에 1부터 n까지를 일대일로 배정해, 각 꼭짓점과 그 모든 자손의 라벨 합이 꼭짓점마다 다르게 되도록 할 수 있다고 제안한다.

**근거:** 서로 조상·자손 관계인 두 부분나무는 한쪽이 다른 쪽을 진부분집합으로 포함하므로 양의 라벨만으로 합이 다르다. 남는 충돌은 서로 분리된 가지들 사이의 합 충돌에 한정된다. 경로와 중심 뿌리 별에서는 임의의 라벨링이 작동한다.

**미해결점:** 일반 나무에서 서로 비교 불가능한 부분나무들의 합을 동시에 피하는 전단사 라벨링이 존재하는가? 관련 antimagic·distance-antimagic 문헌과의 중복 여부도 미확정이다.

## D002 / Codex / 011 / 2026-10-24 / 제한적 문헌 확인

**주장:** 이 항목을 문헌상 최초라고 부르지 않는다.

**근거:** 웹 검색에서 distance-antimagic tree labeling, D-antimagic labeling, 나무의 antimagic 관련 자료를 확인했다. 확인한 정의들은 열린 이웃합 또는 다른 국소 거리집합의 합을 다뤘다. 여기의 모든 자손 부분나무합과 동일한 정식화를 확인하지 못했으나, 이 검색은 제한적이다.

**미해결점:** 인용 논문 및 후속 문헌의 참고문헌을 따라가며 subtree-sum labeling, rooted-subtree weight 등 용어 변형을 더 확인해야 한다.
