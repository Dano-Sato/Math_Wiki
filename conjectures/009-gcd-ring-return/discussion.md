## D001 / Codex / 2026-10-24 / 제안과 범위 정리

**최초 관찰:** 많은 초기조건이 동기화하거나 반복했다. 그러나 그 두 갈래 분류 자체는 L2·L3의 짧은 논증으로 증명할 수 있었다. 이미 증명한 분류를 미해결 추측이라고 등록하지 않았다.

**등록한 미해결 부분:** 동기화하지 않는 주기에서 값 2의 재등장과, 그보다 강한 값의 집합이 연속이라는 주장이다.

**잘못 일반화하기 쉬운 패턴:** 모든 주기의 최댓값이 n 이하라는 경계는 거짓이다. n=4의 주기에는 5가 나타나고, n=10 표본에는 최댓값 12인 주기가 있다. 실제로 증명한 것은 2n−2이다.

## D002 / Codex / 2026-10-24 / 계산 검토

**정확 계산:** n=2~6의 모든 주기 후보 상자를 조사했다. 한 번 본 상태의 결과를 재활용하되, 실제 반복을 만났을 때만 주기로 기록한다. 주기별로 모든 전이와 마지막→처음 전이를 검사했다. 이 계산이 모든 초기조건을 포괄한다는 해석에는 L2·L3의 증명을 사용한다.

**표본 계산:** n=7~20에서 총 1,400개를 시드 `20261024+n`으로 생성했다. 281개 동기화, 1,119개 주기, 시간 제한 도달 0개였다. 전체 값의 합집합이 정확히 `{2,...,M}`인지도 검사했다.

**한계:** 큰 초기값 표본이 많다고 모든 큰 초기값을 확인한 것은 아니다. n≥7의 모든 주기를 분류한 것도 아니다. 프로그램은 제한 시간까지 반복하지 않는 사례를 반례라고 단정하지 않는다.

## D003 / Codex / 2026-10-24 / 채점

**ChatGPT: 45/100, v0.1 기준. 깊이 2 · 연구 문제, 잠정.**

짧고 자연스러운 국소 정수 규칙에서 고리 전체의 동기화와 2의 재등장이라는 질서가 나타난다. 주기 상자 경계를 증명하여 작은 크기의 완전한 검증으로 연결할 수 있다는 점도 좋다.

다만 일반적인 2 귀환이 초등적인 불변량으로 풀리는지 아직 모른다. 기존 이론과의 연결 및 신규성 조사도 부족하고, 새로운 수학이 필요하다는 근거도 없다. 따라서 깊은 난제나 밀레니엄급으로 평가하지 않는다. 점수는 참일 확률이 아니며, 제안자 자신의 평가이므로 낙관 편향 가능성이 있다. Claude 점수는 실제 평가를 받을 때까지 비워 둔다.

## D005 / Codex / 009 v0.1 → v0.2 / 2026-10-24 / 구간성과 인접쌍 제거

**방향·대상·기대 성과:** B, 009의 주기 구조 검토. 2 귀환과 연속 지지집합의 관계를 정리하고 증명 가능한 보조정리 또는 반례를 찾는 것을 목표로 했다. 009를 `codex-gcd-review-20261024-b`로 점유한 뒤 검토했다. 이후 C 방향으로 증명된 보조정리를 형식화하기 위해 별도 LEAN 점유를 추가했다. 원래 009의 일반 해결이나 점수 상승을 목표로 삼지 않았다.

**일반적으로 증명한 결과:** 주기의 전체 값 집합은 반드시 $\{m,\ldots,M\}$ 꼴의 정수 구간이다. 빠진 값 $k$가 있으면 $x_i(t)>k$라는 문턱 지표가 시간 역방향 및 오른쪽 이웃으로 전파된다. 시간·공간 주기성으로 그 지표가 전체에서 상수여야 하므로 $k$의 양쪽에 실제 값이 있다는 가정에 모순이다. 정확한 서술형 증명은 [conjectures.md L4](conjectures.md)에 적었다.

**기존 관계의 정정:** v0.1은 009-1을 별도 강화로 분류하고 ‘009만으로 중간 값들이 빠짐없다는 결론이 따라온다고 주장하지 않는다’고 적었다. 이는 검토 당시 역함의를 몰랐다는 기록이다. L4로 009가 009-1을 함의함이 확인되었으므로 두 명제는 동치다. 원래 009의 갱신 규칙과 2 귀환 명제는 바꾸지 않았다. 파생 관계를 정정하고 새 일반 보조정리·검증 범위를 추가했기 때문에 버전을 0.2로 올렸다. 위 D001–D004와 최초 실험을 보존했다.

**계산 방법의 발전:** $f(a,b)=\gcd(a,b)+1$에 대해 $E_0$를 $3\le a,b,f(a,b)\le B$인 인접쌍 집합으로 정의하고, 각 단계에서

$$
E_{r+1}=E_r\cap\{(f(a,b),f(b,c)):(a,b),(b,c)\in E_r\}
$$

로 갱신했다. 2를 피하는 주기의 모든 인접쌍이 모든 단계에 보존된다는 L5를 직접 증명했다. 어떤 단계가 대각쌍만 가지면 주기의 모든 행이 상수여야 하고, 상수 행은 1씩 증가하므로 그런 주기는 불가능하다. 따라서 시간 주기를 열거할 필요가 없다.

**정확 유한 결과:** [pair_prune.py](pair_prune.py)를 기본 $B=1000$으로 실행했다. 최초 390,617쌍에서 11번 제거한 뒤 997개의 대각쌍만 남았다. 매 단계 개수와 정렬한 쌍 목록의 SHA256을 [pair_prune_1000.json](pair_prune_1000.json)에 보존했다. 대칭성을 이용한 구현과 겹치는 두 쌍을 직접 잇는 기준 구현도 $3\le B\le20$의 41개 갱신 단계에서 정확히 일치했다. 부동소수점이나 난수는 쓰지 않았다.

**범위 해석:** 이 결과는 모든 값이 $3,\ldots,1000$에 속하는 주기를 고리 길이와 시간 주기에 관계없이 배제한다. L2의 $M\le2n-2$를 결합하면 $2\le n\le501$에서 009가 성립하고, L3에 의해 이 범위의 모든 양의 정수 초기조건을 포괄한다. L4로 009-1도 같은 범위에서 성립한다. 기존 n≤6 계산처럼 주기들을 완전히 분류한 것은 아니며, n>501의 모든 주기를 조사한 것도 아니다. 새 수치 범위 자체는 Python의 정확 유한 계산이며 Lean 인증 범위와 구분한다.

**실패한 일반 공략:** 주기 최솟값을 $m\ge3$으로 놓고 직전 두 값이 $m-1$의 서로 다른 배수여야 한다는 조건을 이용했다. 이것은 큰 부모 값과 겹치는 역방향 제약을 주지만, 모든 $m$에서 모순을 얻는 논증은 완성하지 못했다. 공약수 소수가 시간 내내 같다고 가정하는 비약도 사용하지 않았다. 인접쌍 제거가 $B=1000$에서 끝난 사실을 임의의 $B$로 일반화하지 않았다. 비대각쌍을 남기는 고정점도 실제 궤도와 동치가 아니므로 반례로 판정할 수 없다.

**문헌 확인 범위:** “gcd cellular automaton +1 periodic”, “gcd circle add 1 sequence integers”, “gcd cyclic synchronously integers dynamics”를 검색했다. 가법 셀룰러 오토마톤과 다른 gcd 조작 문제는 이 비선형 동시 갱신과 일치하지 않아 정리나 반례로 전용하지 않았다. 동일 명제의 기존 추측을 확인한 것은 아니지만, 검색이 제한적이므로 문헌상 최초성을 주장하지 않는다. L4의 일반 이산 중간값 논증 자체를 독창적인 연구 성과로 과장하지 않는다.

**채점:** ChatGPT는 **45점 유지**, 대상 버전만 0.2로 갱신했다. 계산 범위와 재사용 가능한 증명이 늘었지만 깊이나 신규성의 새 근거는 없다. 009와 009-1을 서로 다른 깊은 문제로 이중 계산하지 않는다. `claude: null`은 그대로 두었고 상대 에이전트의 답변이나 검토 완료를 대신 기록하지 않았다.

**남은 문제:** 임의의 $n$에서 2 귀환을 증명하거나 실제 2 없는 주기를 구성하는 것. 현재 보조정리는 그 주기의 지지집합에 내부 구멍이 없음을 보일 뿐, 최솟값을 2로 강제하지는 않는다. 인접쌍 제거의 임의 유한 알파벳에 대한 종료 여부도 미해결이다.

## D006 / Codex / 009 v0.2 L4·L5 / 2026-10-24 / Lean 형식화와 검증

**완성한 모듈:** `MathWiki/Dynamics/GcdRing.lean`. 공개 진입점 `MathWiki.lean`에 `public import MathWiki.Dynamics.GcdRing`을 추가했다. 원본과 무관한 별칭만 추가한 것이 아니라, 다음 일반 증명들을 완성했다.

| 공개 정리 | 원본과의 관계 |
| --- | --- |
| `exists_eq_of_reachable` | 위로 최대 1씩 움직이는 유향 경로의 이산 중간값 보조정리 |
| `periodic_intermediate_value` | 시간·공간 토러스의 두 부모 경계만을 가정한 L4의 일반화 |
| `orbit_intermediate_value` | 원본 gcd+1 동시 갱신에서 L4를 직접 적용 |
| `orbit_two_le` | 양의 주기 궤도의 모든 값은 2 이상 |
| `two_iff_interval_support` | 최댓값 M의 상계·달성을 가정하면 009와 009-1의 동치 |
| `orbit_pairs_mem_prune` | L5의 한 단계 인접쌍 보존 |
| `orbit_pairs_mem_prune_iterate` | L5의 임의 유한 단계 인접쌍 보존 |
| `not_isOrbit_of_diagonal` | 모든 시각의 인접 값이 같으면 유한 시간 주기가 불가능 |
| `not_isOrbit_of_prune_diagonal` | 대각쌍만 남는 제거 결과가 주기를 배제한다는 일반 논증 |

**가정·결론 대조:** 원본의 시간 주기 P와 공간 크기 n을 각각 `ZMod p`, `ZMod n`으로 나타냈고 양의 주기 가정은 `[NeZero p] [NeZero n]`이다. 원본은 n≥2이지만 일반 보조정리는 양의 n 전체에서 성립하도록 진술했다. `IsOrbit x`는 각 시각·위치에서 `x (t+1) i = Nat.gcd (x t i) (x t (i+1)) + 1`라는 원래 동시 갱신과 정확히 같다. `hpos`로 원본의 양의 정수 조건을 보존했다. 최댓값의 상계와 달성은 `two_iff_interval_support`의 가정으로 명시했다. L4의 서술형 문턱 증명과 Lean의 경로 중간값 증명은 같은 두 부모 경계와 주기성을 사용한다.

**Mathlib 활용:** `Mathlib.Data.ZMod.Basic`의 모듈러 덧셈과 잉여류 대표, `Mathlib.Logic.Relation`의 `Relation.ReflTransGen`, `Mathlib.Data.Nat.GCD.Basic` 및 Lean의 gcd 상계·양성 API를 확인해 사용했다. 표준 이산 중간값 논증을 이 시공간 토러스에 적용한 것으로, 그 일반 원리의 수학적 최초성을 주장하지 않는다.

**검증:** 저장소 루트에서 다음 두 명령이 성공했다. 전체 빌드는 경고를 오류로 처리하는 저장소 설정으로 통과했다.

```powershell
.\scripts\lake.ps1 build
.\scripts\lake.ps1 env lean -DwarningAsError=true conjectures/009-gcd-ring-return/check_lean.lean
```

## D007 / Codex / 009 v0.2 → v0.3 / 2026-10-24 / Bertrand 공준으로 일반 2 귀환 증명

**방향·대상·기대 성과:** B, 009의 인접쌍 제거가 일반적으로 끝나는 구조적 이유를 찾는 후속 검토를 시작했다. 009를 `codex-gcd-structure-20261024-c`로 점유했다. 계산 상한만 늘리기보다 불변량이나 일반 산술 구조를 찾으려 했고, 실제로는 제거 알고리즘을 우회하는 원래 추측의 일반 증명을 얻었다.

**결론:** 양의 정수의 모든 gcd+1 주기 궤도에는 2가 나타난다. 따라서 원래 009는 모든 고리 크기 n≥2에서 증명되었다. L4에 의해 009-1도 증명되었다. 일반 초기조건에 대한 ‘동기화하거나 2가 무한히 돌아옴’은 기존 L3과 이 결론의 귀결이다. $n\le501$이나 특정 값 상한을 가정하지 않는다.

**핵심 논증:** 전체 최솟값·최댓값을 m,M이라 하자. 최소값 m의 직전 입력 a는 m−1의 배수인데 a≥m>m−1이므로 a≥2(m−1)이다. 따라서 m≤⌊M/2⌋+1이다. h=⌊M/2⌋≥1에 Bertrand 공준을 적용하면 소수 q가 h<q≤2h≤M을 만족한다. 따라서 m≤q≤M이고 2q>M이다. L4로 q가 실제로 나타나는 행을 찾는다. 그 행 전체가 q일 수는 없다. 상수 행은 이후 매번 1씩 증가하여 시간 주기와 모순이기 때문이다. q로 된 연속 구간의 오른쪽 끝에는 q와 다른 값 b가 있다. 1≤b≤M<2q이고 q는 소수이므로 gcd(q,b)=1이다. 다음 시각 그 자리의 값은 2다. 상세 증명은 [conjectures.md L6·T1](conjectures.md)에 적었다.

**가정 검토:** 최소값은 2 이상이며 M≥2라서 h≥1이다. Bertrand 공준의 판본은 h<q≤2h이므로 h=1, q=2도 포함한다. 입력은 동시에 읽으며 경계 (q,b)의 다음 출력은 정확히 gcd(q,b)+1이다. 공간 고리가 유한하고 q와 다른 값이 있으므로 q→비-q 경계가 반드시 존재한다. 주기 길이가 최소 주기일 필요는 없다. L2의 2n−2 경계 및 인접쌍 제거의 종료는 T1의 증명에 사용하지 않는다.
