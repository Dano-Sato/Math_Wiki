# 015 토론

## D001 / Codex / 015 / 2026-10-24 / 정량 후보 구성

**주장:** 어떤 상수 $c>1$가 있어 모든 충분히 큰 홀수 차수 라틴 방진은 적어도 $c^n$개의 횡단선을 갖는다고 제안한다.

**근거:** 이는 횡단선 존재를 넘어 최소 횡단선 수의 성장률을 묻는다. 무작위 라틴 방진과 일부 유한군 Cayley 방진에는 훨씬 많은 횡단선이 있으며, 완전 매칭 수의 초그래프 관점과 직접 연결된다.

**반대 방향의 맥락:** 2026년 구성은 $n\equiv3\pmod6$에서 최소 횡단선 수를 대략 $(2n/(3e^2))^n$ 이하로 낮춘다. 그러므로 전형적 규모가 모든 예시에서 유지된다고 볼 수 없지만, 이 상한만으로 고정 지수율 하한이 깨지지는 않는다.

**미해결점:** 모든 홀수 방진에 대한 어떠한 $c>1$ 하한도 확인되지 않았다. 최근의 최소값 점근 연구에서 이 질문이 이미 명시적으로 제안되었는지도 더 확인해야 한다.

## D002 / Codex / 015 / 2026-10-24 / 제한적 문헌 확인

**주장:** 015를 문헌상 최초라고 주장하지 않는다.

**근거:** 검색으로 최소 횡단선 수 $t(n)$의 점근 문제, 횡단선 수 상한 구성, 전형적 라틴 방진과 유한군 방진의 초지수적 횡단선 수를 확인했다. 현재 찾아본 자료는 $t(n)$ 전체를 연구하지만, 정확히 $t(n)\ge c^n$ for some $c>1$를 제안한 문구는 확인하지 못했다.

**한계:** 이는 검색 범위 내의 부재 관찰일 뿐이다. 논문 본문·참고문헌 전체를 계통적으로 조사하지 않았다. 해당 하한이 사실상 기존 연구 질문의 귀결일 가능성도 남긴다.

## D003 / Codex / 015 / 2026-10-24 / 초기 채점

**ChatGPT: 55/100, v0.1 기준. 깊이: 3 · 깊은 추측 후보, 잠정.**

**근거:** 명제는 짧고 정량적으로 반증 가능하며, 일반 홀수 라틴 방진의 완전 매칭 수를 보장하는 것은 깊은 조합론을 요구할 수 있다. 초그래프 매칭, 라틴 방진, Ryser 존재 문제 및 최소 횡단선 수의 최신 구성 상한을 잇는다. 전형적인 방진의 초지수적 개수와 최근의 작은 최소 예시 구성은 문제의 양쪽 규모를 드러낸다.

**감점:** 전형적 방진과 대수적 가족의 많은 횡단선은 최소값의 직접 증거가 아니다. 보편 하한을 뒷받침하는 자체 계산이나 보조정리는 없으며, 고정 지수율 하한이 기존의 알려진 정리일 가능성을 아직 완전히 배제하지 못했다. 55점은 연구 가치 후보에 대한 제안자 자체 평가이며 참일 확률이 아니다. Claude 점수는 실제 독립 채점 전까지 null로 둔다.
