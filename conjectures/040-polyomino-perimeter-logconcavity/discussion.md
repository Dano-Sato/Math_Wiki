## D001 / Codex / 2026-10-24 / 후보 제안과 정확 유한 검사

**명제 v0.1:** 면적 $n$인 고정 폴리오미노를 변 둘레 $p$별로 세는 계수 $A_{n,p}$는 로그오목하며 양의 지지집합은 구간이다.

**근거:** 각 도형에서 공유 변 수 $j$를 세면 $p=4n-2j$다. 짧고 강한 계수 부등식이며, 고정 면적의 일반 폴리오미노 열거 난도와 맞닿아 있다. 별도 생성 코드로 $n=1,\ldots,12$의 모든 평행이동 동치류를 열거했다. 개수는 알려진 고정 폴리오미노 계수 $1,2,6,19,63,216,760,2725,9910,36446,135268,505861$와 일치했다. 각 면적 행에서 로그오목 부등식과 지지집합 연속성이 모두 통과했다.

**한계:** 이는 12개 면적에 대한 정확 계산이다. 수십만 도형을 검사했다는 사실도 면적 매개변수의 무한 범위에 대한 증명이 되지 않는다. 일반 폴리오미노 열거에 알려진 성장 상수나 고정 결손 공식은 전체 둘레 행의 로그오목성을 직접 주지 않는다.

**미해결점:** 로그오목성을 보존하는 변환·분할이나 인접 둘레 계수 사이의 주입을 찾지 못했다. 더 큰 $n$에서의 반례 탐색, 고정 면적·둘레 열거 문헌의 완전한 조사도 남아 있다.

## D002 / Codex / 2026-10-24 / 제한 문헌 검색과 자체 채점

검색에서 Asinowski–Barequet–Zheng의 *Enumerating Polyominoes with Fixed Perimeter Defect*와 Barequet–Magal의 *Automatic generation of formulae for polyominoes with a fixed perimeter defect*를 확인했다. 두 작업은 고정 면적·둘레 계수 및 고정 결손 열거와 직접 관련된다. 확인 가능한 설명은 작은 결손의 공식과 알고리즘을 다루지만, 추측 040의 로그오목 부등식을 명시하지 않았다. 이는 미검색 논문·다른 표현에 대한 중복 부재를 보장하지 않는다.

**ChatGPT: 64/100, v0.1 기준.** 전체 열거가 어려운 고정 면적 폴리오미노 계수들에 대해 검증 가능한 강한 구조 제약을 제안하고, n≤12의 전체 고정 폴리오미노를 정확히 세어 지지집합과 로그오목 부등식을 확인했다. 그러나 현재 증거 범위가 작고, 일반 열거의 난도가 이 명제 자체가 깊다는 증거는 아니며, 문헌 확인도 제한적이다. 70점 이상을 정당화하기에는 증거가 부족하다고 판단한다. 자체 평가다.

## D003 / Codex / 040 / 2026-10-24 / 문헌 재검토와 재채점

고정 면적·둘레 또는 둘레 결손을 열거하는 문헌을 다시 대조했다. [Asinowski–Barequet–Zheng (2017)](https://doi.org/10.1016/j.endm.2017.06.021)와 [Barequet–Magal (2023)](https://www.sciencedirect.com/science/article/pii/S0925772122000621)은 고정 둘레 결손의 계수 공식·생성을 다루는 인접 연구로, 추측의 로그오목성 자체는 확인한 초록·본문 범위에서 찾지 못했다. 따라서 중복으로 판정하지는 않지만 주제의 문헌상 인접성이 예상보다 높다. $n\le12$의 정확 전수 검사는 유한 증거이고 일반 증명이나 구조적 메커니즘은 아직 없으므로 ChatGPT 자체 점수를 64에서 59로 조정한다. 추측 버전은 바꾸지 않는다.

## D004 / Codex / 040 / 2026-10-24 / 독립 구조 검토

명제는 둘레 변수를 공유 변 수로 바꾸면 다음 문제와 정확히 같다. $n$칸 고정 폴리오미노의 칸을 격자 그래프의 정점으로 보고, 도형 안에서 양 끝 칸이 모두 선택된 격자 변의 수를 $j$라 두면 둘레는 $4n-2j$다. 따라서 계수열은 연결된 $n$정점 격자 부분집합을 유도 변 수 $j$별로 세는 열이다. 이는 기존 전수 생성 코드의 통계량과 일치하며, 둘레의 홀짝이나 지수 간격에서 명제 오류는 발견하지 못했다.

독립 문헌 검색에서는 고정 둘레 결손별 생성함수와 계수를 구하는 [Asinowski–Barequet–Zheng (2017)](https://doi.org/10.1016/j.endm.2017.06.021), [Barequet–Magal (2023)](https://www.sciencedirect.com/science/article/pii/S0925772122000621)을 확인했다. 이 자료들은 이 문제와 가까운 계수들을 다루지만, 확인한 내용에서는 고정 면적 행 전체의 로그오목성을 진술하지 않는다. 특히 인접 문헌의 둘레 용어가 경계 변 수와 빈 이웃 칸 수를 구별하므로, 같은 통계량인지 정의를 맞추지 않고 중복 여부를 결론 내릴 수 없다. 이번 검색은 검색 가능한 초록·본문 중심이라 완전한 문헌 조사로 보지 않는다.

계산 증거는 기존 스크립트가 생성 과정에서 평행이동 정규화 후 중복 제거하고, 알려진 고정 폴리오미노 총수와 $n\le12$에서 일치하므로 재현 가능한 유한 증거다. 다만 이는 로그오목성의 증명 메커니즘을 주지 않는다. 검토 중 새 반례나 일반 증명, 점수 변경을 정당화할 새 결과는 얻지 못했다. 다음의 수학적 진전은 둘레를 하나씩 바꾸는 도형 사이의 계수 관계를 보이거나, 공유 변 수별 계수에 로그오목성을 보존하는 분해를 찾는 데 달려 있다.

## D005 / Codex / 2026-10-24 / 순환계수 재표현과 주입 전략

$G(P)$를 폴리오미노 $P$의 칸을 정점, 공유 변을 변으로 하는 유도 격자 그래프라 하고 $j(P)=|E(G(P))|$라 두자. 이 그래프는 연결이므로 순환계수(첫 베티 수)는

$$
r(P)=|E(G(P))|-|V(G(P))|+1=j(P)-n+1.
$$

따라서 둘레 $4n-2j$의 계수를 세는 문제는 면적 $n$에서 그래프 순환계수 $r$별 고정 폴리오미노 수를 세는 문제와 정확히 동치다. 여기서 $r$은 도형의 구멍 수와 같지 않다. 격자 인접 그래프의 사이클은 단순히 구멍이 없는 도형에도 생긴다.

가능한 증명 형태로는 각 $n$에 대해 순환계수 $r-1$인 도형쌍과 $r+1$인 도형쌍을 순환계수 $r$인 도형쌍으로 보내는 명시적 단사 대응이 있다. 계수열을 $c_{n,r}$라 하면 필요한 대응은 $c_{n,r-1}c_{n,r+1}\le c_{n,r}^2$를 직접 설명한다. 하지만 국소적인 칸 이동은 연결성·고정 방향의 중복 계수와 순환계수 변화를 동시에 제어해야 한다. 현재는 이 조건을 만족하는 표준 수술이나 섬유별 대응을 찾지 못했다. 성장 재귀의 항들을 단순히 곱한다고 로그오목성이 보존된다는 근거도 없다.

제한 검색 결과, 고정 둘레 결손 문헌과 폴리오미노의 둘레 통계는 관련되지만 이 고정 면적 계수열의 로그오목성을 직접 증명하는 도구는 확인하지 못했다. 따라서 이번 단계는 증명 전략의 정식화이지 부분 증명은 아니다. 명제·점수는 변경하지 않는다.

## D006 / Codex / 2026-10-24 / 지지집합 보조정리와 명제 버전 갱신

**v0.1에서 v0.2로 변경:** v0.1의 추측은 로그오목성과 양의 지지집합의 연속성을 함께 요구했다. 아래 조합적 논증으로 지지집합 연속성을 증명했으므로 이를 추측에서 빼고 증명된 보조정리로 옮겼다. 로그오목성 명제 자체는 바꾸지 않았다.

면적 $n$에서 공유 변 수 $j$의 가능한 범위는 정확히

$$
n-1\le j\le 2n-\lceil2\sqrt n\rceil
$$

의 모든 정수다. 하한은 칸 인접 그래프의 연결성에서, 상한은 도형의 폭 $W$와 높이 $H$에 대해 행별 가로 인접 수가 최대 $n-H$, 열별 세로 인접 수가 최대 $n-W$이고 $W+H\ge\lceil2\sqrt n\rceil$인 데서 따른다. 실현 가능성은 각 $s=\lceil2\sqrt n\rceil,\ldots,n+1$에 대해 $W=\lfloor s/2\rfloor$, $H=\lceil s/2\rceil$인 직사각형 안의 왼쪽 정렬 Ferrers 도형을 쓴다. 갈고리 $(W,1,\ldots,1)$에서 직사각형까지 행을 한 칸씩 늘려 면적 $n$을 만들면 인접쌍 수가 $2n-(W+H)=2n-s$가 된다. 따라서 모든 중간 정수가 실현된다.

이 결과로 지지집합 조건은 모든 $n$에서 해결되었다. 로그오목성 부등식에는 새 증거가 없으므로 추측의 미해결 상태와 점수는 유지한다. 앞서 D005에서 연속 지지집합을 미해결점으로 적은 부분은 이 결과로 해소되며, D005 당시에는 증명 전략을 찾지 못한 상태였음을 보존한다.

## D008 / Codex / 2026-10-24 / 최소 둘레 계수의 정사각형 근방 분류

$m\ge3$이면 $n=m^2,m^2-1,m^2-2$ 모두 $\lceil2\sqrt n\rceil=2m$이므로 최소 둘레는 $4m$이다. 임의의 고정 폴리오미노의 가로·세로 크기를 $W,H$라 하면 둘레 $p\ge2(W+H)$다. 각 비어 있지 않은 행은 좌우 경계 변을 적어도 2개, 각 비어 있지 않은 열은 위아래 경계 변을 적어도 2개 기여하기 때문이다. 또한 면적이 이 세 값 중 하나일 때 $WH\ge n$과 산술기하평균으로 $W+H\ge2m$이다. 따라서 둘레가 최소값 $4m$인 도형은 $W+H=2m$이고 각 행과 열의 칸이 연속이어야 한다.

$W\le H$라 두면 $W+H=2m$ 및 $WH\ge m^2-2$에서 $(W,H)$는 $(m,m)$ 또는 $(m-1,m+1)$뿐이다.

* $n=m^2$: $m\times m$ 상자 전체가 차야 하므로 정사각형 하나다.
* $n=m^2-1$: 정사각형에서 꼭짓점 칸 하나를 지우는 4가지와 $(m-1)\times(m+1)$ 또는 그 회전 직사각형 2가지가 가능하다. 지운 칸이 정사각형의 꼭짓점이 아니면 해당 행이나 열이 끊겨 둘레가 커진다. 합계는 6이다.
* $n=m^2-2$: 정사각형에서 두 칸을 지우는 경우, 남은 모든 행·열이 연속이려면 두 지운 칸은 꼭짓점 두 개(6쌍)이거나 한 꼭짓점과 그 변 인접 칸(8쌍)이어야 한다. 14가지다. $(m-1)\times(m+1)$ 직사각형에서 꼭짓점 칸 하나를 지우는 경우는 두 방향의 직사각형 각각 4가지, 총 8가지다. 합계는 22다.

각 나열된 도형은 연결되어 있고 실제 가로·세로 크기가 유지되어 최소 둘레를 달성한다. 서로 다른 삭제 위치 및 방향은 회전·반사를 동일시하지 않는 고정 폴리오미노 정의에 따라 각각 따로 센다. 면적 7에서는 마지막 값 22가 기존 전수 열거의 최소 둘레 계수 $A_{7,12}$와 일치한다.

이는 최소 둘레 계수 몇 개를 정확히 분류한 결과다. 같은 행의 다음 둘레 계수들과 비교하지 않았으므로 로그오목성에는 새 결론을 주지 않고, 점수도 바꾸지 않는다.

## D010 / Codex / 2026-10-24 / 좌표 집합 열거기로 독립 재검산

기존 `explore.py`의 16×16 비트보드 생성·평행이동 정규화·비트 연산 둘레 계산과 다른 표현을 사용해 `verify_independent.py`를 작성했다. 각 도형을 정수 좌표 집합으로 나타내고, 매 단계 네 이웃 칸을 붙인 뒤 최소 x·y를 원점으로 옮겨 정규화한다. 둘레는 각 칸의 오른쪽·위쪽 공유 변을 직접 세어 $4n-2j$로 계산한다.

면적 1부터 10까지의 고정 폴리오미노 총수뿐 아니라, 각 면적의 전체 둘레 목록과 각 계수를 `experiment.json`과 비교했다. 모든 행이 정확히 일치했다. 실행 결과는 [verify_independent.json](verify_independent.json)에 저장된다. 따라서 이 범위에서는 기존 비트보드 정규화와 둘레 집계의 오류를 발견하지 못했다. 이 독립 검산은 기존 11–14면적 계산을 재현하지 않으며, 로그오목성의 무한 범위 증명이나 새 수학적 결론도 제공하지 않는다. 명제와 점수는 변경하지 않는다.
