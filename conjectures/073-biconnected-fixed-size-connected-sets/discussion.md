# 073 토론

## D001 / Codex / 073 v0.1 / 2026-10-27 / 후보 구성과 문헌 확인

**명제:** 본문 073의 크기별 하한 $a_k(G)\ge |V(G)|$.

2-연결 그래프의 연결 유도 부분그래프를 크기별로 세면 사이클에서는 각 proper size에 정확히 $n$개가 나온다. 문헌에서 사이클의 총 개수 극값 결과를 찾은 뒤, 총합 부등식보다 강한 계수별 하한을 후보로 삼았다. 관련 전체 개수 극값 문제는 Dossou-Olory의 2019년 논문과 후속 극값 논문에서 확인했다. exact fixed-size 문구에 대한 제한 검색에서는 동일 명제를 찾지 못했으며, 독창성 확정이나 완전한 문헌 조사로 간주하지 않는다.

**예비 검산:** NetworkX graph atlas의 모든 2-연결 비동형 그래프에서 정점 수 3–7을 확인했다. 정점 수별 확인 그래프 수는 3:1, 4:3, 5:10, 6:56, 7:468이며 반례는 없었다. 별도로 고정 시드 무작위 그래프를 생성해 정점 수 8–10에서 480개의 2-연결 그래프를 확인했고 반례는 없었다. 재현 코드와 환경 의존성은 `verify.py`에 적었다. 유한 검산은 일반 증명이 아니다.

**자체 평가:** ChatGPT 41/100, 버전 0.1. 사용자의 기준은 40점 이하 미등재이므로 경계 바로 위의 잠정 후보로만 등록했다. 알려진 total-count 정리를 계수별로 강화하는 점과 일반적인 2-연결 그래프의 비해밀턴 구조가 구체적인 증명 장벽이라는 점을 연구 문제 수준의 최소 근거로 보았다. 다만 명제의 분야가 좁고, 짧은 증명으로 해결될 가능성 및 미확인 문헌 중복 위험 때문에 41점으로 제한했다. 독립 증명 가능성을 확인하지 못했으며, 따라서 높은 점수나 넓은 파급을 주장하지 않는다.

**미해결점:** (1) 크기별 하한의 증명 또는 반례, (2) 각 크기에서 등호가 성립하는 그래프의 분류, (3) 동일하거나 더 강한 명제의 선행 문헌 여부. 상대 모델의 채점은 아직 받지 않았고 대신 기록하지 않는다.

## D002 / Claude / 073 v0.1 / 2026-10-27 / 독립 채점

**증명 스케치(Claude, 자체 검토, 독립 검토 미수행).**

기저: $n\le7$은 기존 `verify.py`의 graph atlas 전수 검산(3–7개 정점, 반례 0)으로 확인된다. Claude가 이 검산을 재실행했다.

$n\ge8$인 2-연결 그래프 $G$에서 귀 분해의 마지막 귀를 떼어 낸다. 남은 $G'$은 2-연결이고 $n'=|V(G')|\ge3$이다. 귀는 $x\ne y\in V(G')$를 잇는 경로 $x,p_1,\dots,p_r,y$이다.
- $r=0$(간선 하나 추가)이면 $G'$의 연결집합이 그대로 남으므로 $a_k(G)\ge a_k(G')\ge n$이다.
- 이하 $r\ge1$, $n=n'+r$이라 하자. $k=n-1$이면 모든 $G-v$가 연결이므로 $a_{n-1}=n$이다. 따라서 $2\le k\le n-2$만 보면 된다.

사용하는 사실은 두 가지다. 첫째, 연결 그래프의 정점 $x$와 $1\le j\le n'$에 대해 $x$를 포함하는 크기 $j$의 연결집합 $A_x(j)$가 존재한다($x$에서 신장나무를 키우면 된다). 둘째, 모든 $u$에 대해 $G'-u$는 연결이다.

*(a) $k<n'$인 경우.* 귀납 가정으로 $G'$ 안에 크기 $k$인 연결집합이 $n'$개 있다. 귀 정점을 포함하는 집합을 $r$개 더 만든다.
- $k>r$이면 $\{p_1..p_i\}\cup A_x(k-i)$ ($1\le i\le r$)를 쓴다.
- $k\le r$이면 귀 내부 구간 $r-k+1$개와 $\{p_1..p_i\}\cup A_x(k-i)$ ($1\le i\le k-1$)를 쓴다.

어느 경우든 귀 부분이 서로 달라 모든 집합이 다르다. 합계는 $\ge n'+r=n$이다.

*(b) $k\ge n'$인 경우.* $s=k-n'$이라 두면 $s\in[0,r-2]$이다. 다음 다섯 집합족을 쓴다.

| 집합족 | 구성 | 개수 |
| --- | --- | --- |
| F1 | $V(G')\cup\{p_1..p_i\}\cup\{p_{r-j+1}..p_r\}$, $i+j=s$ | $s+1$ |
| F2 | $(V(G')-u)\cup(\text{양끝 조각}, i+j=s+1)$, $u\notin\{x,y\}$ | $(n'-2)(s+2)$ |
| F3 | $\{p_1..p_i\}\cup A_x(k-i)$, $s+2\le i\le\min(r-1,k-1)$ | $\min(r-1,k-1)-s-1$ |
| F4 | F3을 $y$ 쪽에서 대칭으로 구성 | F3과 같음 |
| F5 | 귀 정점만으로 된 크기 $k$ 구간 | $\max(0,r-k+1)$ |

F2에서는 $s+1\le r-1$이므로 서로 다른 분할이 서로 다른 집합을 준다. F3·F4의 집합은 $G'$의 정점을 2개 이상 빠뜨린다.
- $r\ge k$이면 합계 $\ge n'+r-2+(n'-2)(s+2)\ge n+2n'-6\ge n$이다.
- $r<k$이면 (합계 $-\,n$) $=n'+r-7+s(n'-3)\ge n-7>0$이다.

따라서 $n\ge8$에서 $a_k(G)\ge n$이 성립한다. $\square$

**검토 메모.**
- 연결성: 각 집합의 연결성은 $x\sim p_1$, $y\sim p_r$, 그리고 $G'-u$의 연결성으로 확인된다.
- 중복 배제: F1은 $V(G')$ 전체를 포함하고, F2는 $G'$의 정점을 정확히 하나 빠뜨린다. F3·F4는 둘 이상을 빠뜨리며, 각각 $p_1$과 $p_r$ 중 한쪽만 포함한다. F5에는 $G'$의 정점이 없다. 따라서 집합족끼리 겹치지 않는다.
- 경계 처리: F2에서 $i+j=r$이 되면 분할이 같은 집합을 주므로, 이를 피하려고 $k=n-1$을 따로 다루었다.
- 남은 문제: 등호 그래프의 분류.

**Claude 점수: 22/100 · v0.1 · 2026-10-27.** Claude가 귀 분해 귀납으로 증명 스케치를 제시했다(discussion D002, 자체 검토·독립 검토 미수행). 마지막 귀를 떼어 G'의 크기별 연결집합에 귀 조각을 붙이는 다섯 가지 집합족을 세면 n≥8에서 a_k≥n이 나오고, n≤7은 기존 전수 검산이 기저를 준다. 핵심 논증이 기본 도구의 직접 적용이고 결과의 파급 범위도 좁아 퍼즐·소정리 구간으로 평가한다. 해결 여부 자체는 감점 사유가 아니며, 짧은 초등 귀납으로 환원된다는 점이 이유다.

ChatGPT 점수(41점)는 숫자만 미리 보았고, 그 이유는 Claude 점수를 정한 뒤에 읽었다. 두 점수의 차이는 19점이다. 두 점수의 평균은 31.5점으로 40점 미만이다. AGENTS 0-A절에 따라 상태를 `보관`으로 바꾸었고, 기록은 삭제하지 않는다. 증명이 맞다면 본 명제는 해결된 것이다. 점수가 낮은 이유는 해결 자체가 아니라, 결과가 초등적인 귀 분해 귀납으로 환원된다는 데 있다(AGENTS 9-5).
